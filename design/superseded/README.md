# Superseded artifacts

Both pages here carry their own hand-written copy of the suite geometry, which is
the duplication that let "54 x 151 ft" survive across three artifacts with
nothing to catch it. Their numbers are wrong and they are kept only as a record.

- `weld15-directions.html` — the visual-direction comparison that selected the
  cyanotype-to-daylight look. That decision still stands; the geometry in it does
  not. Its campus renders are still accurate, since they came from the GIS data.
- `weld15-plan-derivation.html` — revision 3 of the plan, drawn as a band across
  the north gable. Superseded: the suite runs **along a facade**, not across the
  gable, and it is L-shaped. See `docs/FINAL-LAYOUT.md`.

The current plan is `design/weld15-plan.svg`, generated by `npm run plan` from
`buildSuite()` and `buildWalls()`. `tests/drift.test.ts` fails if it goes stale.
